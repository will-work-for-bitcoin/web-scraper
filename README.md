# web-scraper

Lightweight web scraping framework - link extraction, email detection, CSS selectors, and export.

## Installation

```bash
git clone https://github.com/will-work-for-bitcoin/web-scraper.git
cd web-scraper
```

## Usage

```bash
python web_scraper.py
python web_scraper.py --help
```

## Features

- Pure Python 3.7+, zero dependencies
- JSON/CSV export support
- Beautiful terminal output
- Easy to extend and customize
